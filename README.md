# Java DSA Daily Practice

Daily Java solutions for data structures and algorithms practice.

## Goal

- Add 2 meaningful commits per day.
- Keep each problem self-contained with explanation, implementation, and tests.
- Prefer readable Java over clever shortcuts.

## Structure

```text
src/main/java/dev/daily/dsa/
src/test/java/dev/daily/dsa/
```

## Run

```bash
mvn test
mvn exec:java
```
