# Subsets

- Date: 2026-10-28
- Difficulty: Medium
- Topic: Backtracking
- Pattern: Include-or-exclude recursion

## Problem

Given an array of distinct integers, return every possible subset, including the empty subset and the complete array. The subsets may be returned in any order.

## Approach

Use backtracking to make one binary decision for each value:

1. Recurse without including the current value.
2. Add the value and recurse again.
3. Remove the value to restore the partial subset for the caller.
4. When every value has been considered, copy the partial subset into the result.

Copying at the base case prevents later backtracking changes from modifying subsets that have already been recorded.

## Complexity

- Time: `O(n * 2^n)` because there are `2^n` subsets and copying one can take `O(n)`.
- Space: `O(n * 2^n)` for the output and `O(n)` auxiliary recursion depth.
