# Min Stack

- Date: 2026-08-18
- Difficulty: Medium
- Topic: Stack, Design
- Pattern: Auxiliary stack for aggregate tracking

## Problem

Design a stack that supports these operations:

- `push(value)`: add a value to the top of the stack.
- `pop()`: remove the top value.
- `top()`: return the top value.
- `getMin()`: return the minimum value currently in the stack.

All operations should run in `O(1)` time.

## Approach

Use two stacks:

- `values` stores every pushed value.
- `minimums` stores the minimum value at each stack depth.

When pushing a new value, compare it with the current minimum and push the smaller value onto `minimums`. This keeps both stacks the same size. When popping, remove from both stacks. The top of `minimums` is always the minimum for the current stack state.

This avoids scanning the stack during `getMin()`.

## Complexity

- Time: `O(1)` for `push`, `pop`, `top`, and `getMin`.
- Space: `O(n)` for the two stacks.
