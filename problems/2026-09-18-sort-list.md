# Sort List

- Date: 2026-09-18
- Difficulty: Medium
- Topic: Linked List
- Pattern: Merge sort, fast and slow pointers

## Problem

Given the head of a linked list, return the list sorted in ascending order.

The target is `O(n log n)` time while reusing the existing nodes.

## Approach

Use merge sort because linked lists can be split and merged without shifting elements.

1. Stop when the current list has zero or one node.
2. Find the midpoint with slow and fast pointers.
3. Disconnect the list into left and right halves.
4. Recursively sort both halves.
5. Merge the two sorted halves by relinking their nodes.

Starting the fast pointer at `head.next` leaves the slow pointer at the end of the left half, which makes the split work for both even and odd lengths.

## Complexity

- Time: `O(n log n)`.
- Space: `O(log n)` for the recursion stack; merging uses `O(1)` extra space.
