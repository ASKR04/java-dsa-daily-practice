# Path Sum

- Date: 2026-09-25
- Difficulty: Easy
- Topic: Binary Tree
- Pattern: Depth-first search, remaining target

## Problem

Given the root of a binary tree and an integer target, determine whether the tree contains a root-to-leaf path whose node values add up to the target.

A leaf has no left or right child. A matching partial path that stops at a non-leaf node does not count.

## Approach

Carry the remaining target through a depth-first traversal:

1. Return `false` for an empty subtree.
2. Subtract the current node's value from the target.
3. At a leaf, return whether the remaining target is zero.
4. Otherwise, recursively search either child with the updated target.

## Complexity

- Time: `O(n)`, because each node may be visited once.
- Space: `O(h)` for the recursion stack, where `h` is the tree height.
