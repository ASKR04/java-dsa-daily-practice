# Same Tree

- Date: 2026-09-23
- Difficulty: Easy
- Topic: Binary Tree
- Pattern: Paired depth-first search

## Problem

Given the roots of two binary trees, determine whether they are structurally identical and every corresponding node has the same value.

## Approach

Traverse both trees together:

1. If either node is `null`, the pair matches only when both are `null`.
2. Otherwise, their values must match.
3. Recursively compare the left subtrees and the right subtrees.

All three conditions must hold for the trees to be the same.

## Complexity

- Time: `O(n)`, where `n` is the number of nodes examined before a mismatch or completion.
- Space: `O(h)` for the recursion stack, where `h` is the tree height.
