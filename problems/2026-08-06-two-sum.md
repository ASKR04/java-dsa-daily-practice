# Two Sum

## Problem

Given an integer array `nums` and an integer `target`, return the indices of two numbers whose values add up to `target`.

If no pair exists, return `[-1, -1]`.

## Approach

Use a hash map from value to index. For every number, compute the complement needed to reach the target. If the complement has already been seen, the current index and the stored index form the answer.

## Complexity

- Time: `O(n)`
- Space: `O(n)`

## Edge Cases

- Duplicate values, such as `[3, 3]` with target `6`
- No valid pair
- Negative numbers and zero
