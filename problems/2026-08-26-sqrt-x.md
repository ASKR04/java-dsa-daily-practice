# Sqrt(x)

- Date: 2026-08-26
- Difficulty: Easy
- Topic: Binary Search
- Pattern: Answer space search

## Problem

Given a non-negative integer `x`, return the square root of `x` rounded down to the nearest integer.

The returned value should be an integer, and the implementation should not use built-in exponent functions.

## Approach

Use binary search over the possible answer range.

1. Values `0` and `1` are their own square roots.
2. For larger values, search between `1` and `x / 2`.
3. Check the middle value using division, `middle <= x / middle`, to avoid integer overflow from `middle * middle`.
4. If `middle` is a valid square root candidate, store it and search to the right.
5. Otherwise, search to the left.

The final stored candidate is the largest integer whose square is less than or equal to `x`.

## Complexity

- Time: `O(log x)`.
- Space: `O(1)`.
