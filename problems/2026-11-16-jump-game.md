# Jump Game

- Date: 2026-11-16
- Difficulty: Medium
- Topic: Greedy
- Pattern: Farthest reachable frontier

## Problem

Each value in a non-empty array represents the maximum distance that can be
jumped forward from that index. Determine whether the final index is reachable
when starting at index zero.

## Approach

Maintain the farthest index reachable from all positions visited so far:

1. Process an index only when it is within the current reachable frontier.
2. Extend the frontier using that index and its maximum jump distance.
3. Return immediately when the frontier reaches or passes the final index.

If the next index lies beyond the frontier, no earlier choice can cross that
gap, so the destination is unreachable. A `long` frontier prevents overflow
when an input contains a very large jump.

## Complexity

- Time: `O(n)`
- Space: `O(1)`
